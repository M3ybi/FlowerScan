# Plantie i18n

Plantie uses a small dictionary-based localization layer in `src/lib/i18n.ts`.

## Languages

Supported language codes match the onboarding preference:

- `en`
- `sk`
- `de`
- `fr`
- `es`

The selected language is stored with the existing `plantie-language-v1` localStorage key from `src/lib/onboarding.ts`.

## Usage

Use `createTranslator(language)` inside React surfaces:

```ts
const t = createTranslator(selectedLanguage);
t("dashboard.hero");
```

Use replacements for dynamic values:

```ts
t("dashboard.tracked", { count: allFlowers.length });
```

## Fallback

Missing language dictionaries or missing keys fall back to English. If a key is missing from English too, the key name is returned. This keeps UI rendering safe during incremental translation work.

## Data Safety

Do not destructively localize database values, plant names, household names, diagnosis user notes, or any user-generated content. Translate only static UI labels, helper copy, empty states, and navigation.

## Adding Text

1. Add the English key first.
2. Add Slovak and other language translations where ready.
3. Use the key through `t("key.name")`.
4. Add or update tests when the language behavior matters.
