# Mobile asset placeholders

This directory documents assets needed before iOS App Store and Google Play submission.

No production mobile assets are generated yet.

Required later:

- `icon-source.png`: high-resolution square app icon source. `icon-source.png.placeholder` marks the pending asset.
- `splash-source.png`: high-resolution splash screen source. `splash-source.png.placeholder` marks the pending asset.
- `screenshots/ios/`: App Store screenshots.
- `screenshots/android/`: Google Play screenshots.

Use the existing `public/plantie-logo.svg` only as a temporary design reference, not as a final store-ready raster asset.
