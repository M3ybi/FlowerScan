# FlowerScan

Mobilná webová aplikácia na evidenciu izbových rastlín, QR štítky, zálievku, presádzanie a poznámky.

## Lokálny vývoj

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Publikovanie

Aplikácia je pripravená na GitHub Pages cez workflow `.github/workflows/deploy.yml`.
